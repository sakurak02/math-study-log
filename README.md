# Math Study Log

## 公開LOG画像の命名ルール

保存先は `content/records/YYYYMMDD/NNN/images/` です。

```text
YYYYMMDD-NNNf[-M].webp
YYYYMMDD-NNNr[-M].webp
```

- `YYYYMMDD`: 学習日。`records/` 直下の日付フォルダと一致させます。
- `NNN`: その日の学習セット番号（`001`, `002`, `003`, …）。親フォルダと一致させます。
- `f`: first（最初の答案）。`r`: retry（公開に採用した1回分の再挑戦答案）。
- `M`: その答案の画像ページ番号。1から始まる整数で、先頭に0を付けません。画像が1枚だけなら枝番を省略できます。複数ページでは `-1` から付けます。
- 種別と拡張子は小文字の `f` / `r` と `.webp` を使用します。

例（同一セット内ではfirst→retry、同じ種別ではページ番号の数値順に掲載）:

```text
content/records/20260828/001/images/
  20260828-001f-1.webp
  20260828-001f-2.webp
  20260828-001r-1.webp
  20260828-001r-2.webp
```

末尾の `-1`, `-2`, `-3` は**リトライ回数ではありません**。
ローカルで何度リトライしても、公開するのは採用した1回分だけです。
例えば2回目のリトライを採用しても、1枚の答案なら公開用に
`20260828-001r.webp`（または `20260828-001r-1.webp`）とリネームします。ローカルの試行履歴は公開ファイル名に含めません。

旧形式（今後は使用不可）:

```text
20260828-001-f.webp
20260828-001-r.webp
20260828-001-1-r.webp
```

枝番なしとページ番号付きの併用、種別が異なる `20260828-001x-1.webp`、
ページ番号が0の `20260828-001r-0.webp` は無効です。

## 記事の分類とカレンダー表示

今後の記事では、`session-f.md` または `session-r.md` の冒頭に
管理用HTMLコメントとして科目・中分類・小分類を指定します。

```md
<!--
subject: 数学III
category: 極限
subcategory: 数列の極限
-->
```

- `subject`: 科目
- `category`: カレンダーに科目と組み合わせて表示する中分類
- `subcategory`: カレンダー詳細と目次に使用する小分類

この管理用コメントは生成HTMLのSESSION本文には表示されません。
同じ記録の `session-f.md`、`session-r.md`、`session-r-extra.md` に分類を書く場合は、
すべて同じ内容にしてください。これらは目次では1記事として扱われ、重複表示されません。
コメントの分類を `meta.json` より優先するため、新規記事では分類目的の
`meta.json` を手入力する必要はありません。既存記事の `meta.json` 分類は
後方互換用として引き続き利用できます。

科目名・中分類名と表示順、スマホ用短縮名は
`content/classification-master.json` で一元管理します。
科目順は数学I、数学A、数学II、数学B、数学III、数学Cです。
同じ日の同じ科目・中分類は1行にまとめ、異なる分類は2行まで表示し、
残りは `+1`、`+2` の形式で表示します。
分類を省略した既存記事は「未分類」として扱われます。
3項目の一部だけを指定した場合や、分類マスターにない科目・中分類はビルドエラーになります。

トップページの「目次」は、科目 → 中分類 → 小分類 → 記事タイトルの順に
ビルド時に自動生成します。6科目は常にマスター順で表示し、記事がない中分類・小分類は
表示しません。同じ小分類の記事は古い学習日から新しい学習日の順に並びます。
目次ファイルを手動で更新する必要はありません。

## ビルドとチェック

```sh
npm ci
npm test
npm run build
```

ビルド時に命名形式、保存先との日付・学習セット番号の一致、複数ページ時の `-1` の存在を確認します。
不正な画像があれば、対象パスと理由を示して停止します。
従来の入力場所 `public/images/` に残っている画像にも新しい命名形式を適用します。
QUESTION画像はこのLOG命名チェックの対象外です。

既存の旧名画像は新形式にリネームし、画像を直接参照している箇所があれば更新してからビルドしてください。
生成物は `public/records/YYYYMMDD/NNN/` に出力されます。
ビルドは各記事の出力先画像を再生成し、旧拡張子を含む不要な生成画像を残しません。

## 学習セットの統合ページとSESSION

各セットは `records/YYYYMMDD/NNN/index.html` にLOGとSESSIONをまとめて表示します。
日付ページの各セットの `OPEN` から開けます。同じ日の `001`・`002`・`003` はそれぞれ別ページです。
トップページの3ボタンは、そのまま各カテゴリの一覧へ移動します。

| ボタン | 一覧ページ | 一覧から開く記事 |
| --- | --- | --- |
| LOG | `log/index.html` | `records/YYYYMMDD/NNN/log.html`（LOG画像のみ） |
| SESSION | `session/index.html` | `records/YYYYMMDD/NNN/session.html`（SESSION本文のみ） |
| QUESTION | `question/index.html` | `question/slug.html`（QUESTION記事） |

LOG一覧には画像があるセット、SESSION一覧には本文があるセット、QUESTION一覧にはQUESTION記事だけを掲載します。
LOGとSESSIONが同じ学習セットに属する場合は、両一覧に同じタイトルが並びますが、記事の遷移先と表示内容は別です。
`log.html` / `session.html` から統合ページへの自動移動は行いません。
日付ページの `OPEN` は引き続き統合ページを開きます。トップページの見た目や他のセクションは変更しません。

新規記事には、小文字の次のファイル名を使用してください。

```text
content/records/20260828/001/
  images/
    20260828-001f-1.webp
    20260828-001r-1.webp
    20260828-001r-2.webp
  session-f.md
  session-r.md
  session-r-extra.md  # 任意
```

- 教材問題ブロック: `f`画像と `session-f.md`。SESSIONには学習内容・ポイント・教材問題での確認・つまずき・考え方を記載し、市販教材の問題文そのものは掲載しません。
- オリジナル問題ブロック: 公開に採用した `r`画像と `session-r.md`。SESSIONには作成した問題文・ヒント・解答・解説・振り返りを記載します。
- 任意の追加解説: `session-r-extra.md`。存在する場合だけ、オリジナル問題のLOG｜SESSIONブロック終了後に、中央寄せ・最大幅900pxの全幅セクションとして表示します。`session-r.md` の右カラムには含めません。
- `f` / `r` は既存の画像命名をそのまま使用し、表示ラベルは「教材問題」／「オリジナル問題」にします。
- 画像は各ブロック左側にまとめ、ページ番号の数値順（1、2、3、…、10）で縦に並べます。問題文やSESSION本文を左に追加しません。
- 各Markdownは従来と同じ数式・`details`・`summary`の記法が使えます。
- SESSIONがまだない場合は右側に未登録の案内を表示します。画像がまだない左側は空欄です。
- タイトルは既存の `meta.json` があればそれを優先し、なければ `session.md`、`session-f.md`、`session-r.md` の順に選び、従来どおりfront matterの `title`、H1見出し、日付・番号の順で決定します。

### 表示

「教材問題」「オリジナル問題」は、それぞれ独立したグリッドを持つ2段のブロックです。
ページ全体を「LOG全部」「SESSION全部」の2本の縦列にする構成は使いません。
幅が900pxを超える画面では、各ブロックを左LOG・右SESSIONの約50:50で表示します。
教材問題の画像が3枚ある場合も、SESSIONが長い場合も、左右両方が収まる高さの後からオリジナル問題ブロックを開始します。
そのためオリジナル問題のLOGとSESSIONの開始高さは常に揃います。
2列は固定で回り込まず、短い側の余白を許容します。カラム単位の独立スクロールはありません。
長い数式・表・コードの横スクロールは従来どおり内容単位で使用できます。
900px以下では教材問題の全LOG画像→教材問題SESSION、続いてオリジナル問題の全LOG画像→オリジナル問題SESSIONの縦並びです。タブ切替はありません。
`session-r-extra.md` がある場合は、その後に追加SESSIONを続けます。ない記事のHTML構造・表示順は従来どおりです。
答案画像はクリック・キーボード操作で拡大でき、閉じるボタンまたはEscapeで戻れます。

### 既存記事との互換性

既存の20260825・20260827・20260828の記事は、オリジナル問題が始まる箇所で一度だけ内容を確認して分割済みです。
その前を `session-f.md`、オリジナル問題から後の解説・振り返りを `session-r.md` に移しました。
数学の本文・数式・ヒント・解答は保持し、20260827の英語パート見出しだけ日本語に変更しています。
移行後の `session.md` は残さず、全文の重複表示を防いでいます。

今後、古い `session.md` のみのセットを追加した場合も、2つのLOG｜SESSIONブロックは常に別々に生成します。
未分類の旧本文は、内容を失わないため、その後に別枠で一度だけ表示します。
正しく対応表示するには内容を確認して `session-f.md` / `session-r.md` に分けてください。
両形式が共存する場合も旧本文は別枠に表示されるので、移行完了後は古い `session.md` を取り除いてください。
ビルド時やブラウザ上で見出しを推測して分割したり、JavaScriptで左右の位置を合わせたりはしません。
recordsの日付／番号構造は変更していません。
