# 無限等比数列――公比を見る前に初項を見る

## 今日のポイント

無限等比数列では、公比の収束条件だけでなく、**最初に初項が 0 になる場合を確認する**ことが大切です。

一般に

$$
a_n=ar^{n-1}
$$

では、$a=0$ なら全項が 0 なので、公比の値にかかわらず数列は 0 に収束します。

そのうえで $a\neq0$ の場合に、公比について収束条件を調べます。

## 今日のつまずき

今回は、公比の条件に意識が向き、初項が 0 になる場合を独立して確認する視点が弱くなっていました。

覚えておきたい順序は、

**初項を見る → そのあと公比を見る**

です。

公式だけでなく、数列全体の構造を見ることを意識します。
